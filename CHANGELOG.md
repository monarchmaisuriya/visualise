# Changelog

## 0.1.0 - 2026-10-25

- `.tldr` files open in the tldraw editor in their file tab and save back on every edit.
- Visualise tab: lists the workspace's drawings, creates `drawings/untitled-<n>.tldr`, and edits in place.
- Outside changes reload the drawing; with unsaved edits you choose Reload or Overwrite.
- Send to tldraw.com: a one-way copy into your tldraw.com account through tldraw.com's import page.
- Licence key setting; production builds without a key show a notice.
